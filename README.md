# Pollen — releases

Pollen is a desktop app: a roster of AI agents you message, each running on a coding-agent CLI you
are already signed in to, with a built-in signed-in browser. It runs on your own computer.

This repository holds the **installers only** — no source. The site, the phone app and everything
else live at <https://pollenai.pages.dev>.

## Download

- Latest Windows installer:
  <https://github.com/oorbitproductivity-oss/pollen-releases/releases/latest/download/Pollen-Setup.exe>

`Pollen-Setup.exe` is the same file as the versioned `Pollen-Setup-<version>.exe` beside it, under
a name that does not change, so a link to it never goes stale.
